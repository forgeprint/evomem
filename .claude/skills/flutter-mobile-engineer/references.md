# References

Every rule in [`SKILL.md`](SKILL.md) and every checklist row rests on one of
these. A row that cites nothing is somebody's opinion and does not belong in a
review ([ADR 0010](../../docs/decisions/0010-review-standards.md)).

Package versions were read from the pub.dev API, and the Flutter and Dart
versions from their release manifests, on the date shown. Where a page carries
no version, the row says what it does carry. **Re-check every 90 days**, and
when the next Flutter stable lands.

> **Next re-check due: 2026-12-24.**
